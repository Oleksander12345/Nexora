# Asset provenance

- Source reference: user-supplied `reference.png`.
- `hero.webp`: Image Gen cleanup of source hero, keeping the panoramic composition, removing UI text and controls.
- `carry.webp`, `details.webp`: Image Gen campaign photographs based on reference composition.
- Product `docs/generated-products/*-v2.webp`: individual Image Gen product photographs based on reference products; transparent backgrounds where available. Serving filenames omit `-v2`.
- `cat-*.webp`: source category photographs extracted from the user reference.
- `home.webp`, `gift.webp`: reference source thumbnails for supplemental mock products.
- Icons: Phosphor Icons package.
- Typefaces: locally served DM Sans and Montserrat via Fontsource.
